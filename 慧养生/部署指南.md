# 部署指南：将本地网页变为公开访问页面

## 方案一：使用 GitHub Pages 部署（推荐）

GitHub Pages 是一个免费的静态网站托管服务，适合部署我们的养生助手网页。

### 步骤 1：创建 GitHub 仓库
1. 登录 [GitHub](https://github.com)
2. 点击右上角的 "+" 按钮，选择 "New repository"
3. 输入仓库名称（例如：hui-yang-sheng）
4. 选择 "Public" 作为仓库类型
5. 点击 "Create repository"

### 步骤 2：将本地项目推送到 GitHub
1. 打开命令行工具（如 Git Bash、PowerShell 或 Terminal）
2. 导航到项目目录：
   ```bash
   cd c:\Users\mac\Desktop\慧养生
   ```
3. 初始化 Git 仓库：
   ```bash
   git init
   ```
4. 添加所有文件到暂存区：
   ```bash
   git add .
   ```
5. 提交更改：
   ```bash
   git commit -m "Initial commit"
   ```
6. 关联 GitHub 仓库（将 `username` 替换为你的 GitHub 用户名，`repository-name` 替换为你创建的仓库名称）：
   ```bash
   git remote add origin https://github.com/username/repository-name.git
   ```
7. 推送到 GitHub：
   ```bash
   git push -u origin master
   ```

### 步骤 3：启用 GitHub Pages
1. 进入你的 GitHub 仓库页面
2. 点击 "Settings" 选项卡
3. 滚动到 "GitHub Pages" 部分
4. 在 "Source" 下拉菜单中，选择 "master branch"
5. 点击 "Save"
6. 稍等几分钟，GitHub Pages 会为你的网站生成一个 URL（格式为：`https://username.github.io/repository-name/`）

## 方案二：使用 Vercel 部署

Vercel 是另一个免费的静态网站托管服务，部署过程更加简单。

### 步骤 1：创建 Vercel 账号
1. 登录 [Vercel](https://vercel.com)
2. 使用 GitHub 账号登录

### 步骤 2：导入项目
1. 点击 "New Project"
2. 选择 "Import Git Repository"
3. 选择你刚刚创建的 GitHub 仓库
4. 点击 "Import"
5. 保持默认设置，点击 "Deploy"
6. 部署完成后，Vercel 会为你的网站生成一个 URL

## 方案三：使用 Netlify 部署

Netlify 也是一个流行的静态网站托管服务。

### 步骤 1：创建 Netlify 账号
1. 登录 [Netlify](https://www.netlify.com)
2. 使用 GitHub 账号登录

### 步骤 2：导入项目
1. 点击 "New site from Git"
2. 选择 "GitHub"
3. 选择你刚刚创建的 GitHub 仓库
4. 保持默认设置，点击 "Deploy site"
5. 部署完成后，Netlify 会为你的网站生成一个 URL

## 注意事项

1. **部署时间**：首次部署可能需要几分钟时间，请耐心等待
2. **URL 访问**：部署完成后，你可以通过生成的 URL 访问你的网站
3. **更新内容**：当你修改了本地代码后，只需将更改推送到 GitHub，托管服务会自动更新网站
4. **DNS 配置**：如果你有自己的域名，可以在托管服务的设置中配置自定义域名

## 验证部署

部署完成后，你可以通过以下步骤验证网站是否正常访问：

1. 打开生成的 URL
2. 测试所有功能，包括症状咨询、养生知识科普的展开/折叠功能等
3. 确认网站在不同设备和浏览器上都能正常显示

恭喜！你的养生助手网页现在已经可以公开访问了！
