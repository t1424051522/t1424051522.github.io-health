# 产品需求文档 (PRD)：AI养生助手 - "慧养生"

**版本：** V1.0  
**状态：** 草案  
**日期：** 2026-02-23  

---

## 1. 文档概览
### 1.1 目的
本文档旨在定义"慧养生"网页产品的核心功能需求，为开发、设计及运营团队提供指导。

### 1.2 产品定位
一款基于AI技术的轻量化养生咨询工具，通过症状分析为用户提供个性化的养生建议及产品组合方案。

---

## 2. 用户画像
| 用户类型 | 核心特征 | 典型场景 |
| :--- | :--- | :--- |
| **银发族 (60+)** | 关注健康，有慢性调理需求，不熟悉复杂操作。 | 感觉最近眼干、睡眠不好，想找点东西泡水喝。 |
| **职场养生族 (25-45)** | 工作压力大，处于亚健康状态，追求高效养生。 | 经常熬夜，肝火旺，想快速找到护肝的产品组合。 |
| **家庭健康管理者** | 为父母或子女寻找养生方案。 | 帮家里老人咨询腿脚无力的调理方法。 |

## 3. 功能需求

### 3.1 核心模块：AI症状咨询
*   **需求描述**：用户通过文本或语音输入当前不适症状。
*   **功能点**：
    *   **模糊输入支持**：支持"肝不好"、"总是想睡觉"、"眼睛干涩"等自然语言。
    *   **多轮引导**：若症状描述不全，AI自动追问（如：持续多久了？是否有其他不适？）。
    *   **风险预警**：若识别到危急重症关键词（如"胸痛"、"呼吸困难"），立即弹出"请立即就医"的红色警告。

### 3.2 核心模块：调理建议与产品推荐
*   **需求描述**：根据分析结果，推送养生方案。
*   **功能点**：
    *   **原因推测**：基于中医理论或营养学给出可能的原因（如：肝气郁结、脾胃虚弱）。
    *   **产品组合推荐**：推荐2-3种产品的组合（如：赶黄草 + 枸杞 + 决明子）。
    *   **功效说明**：简述每种产品的养生作用，严禁使用"治疗"、"治愈"等词汇。

### 3.3 辅助模块：合规与免责
*   **需求描述**：确保产品符合法律法规。
*   **功能点**：
    *   **强制免责声明**：首次进入及每次结果页底部必须显示"本建议仅供参考，不作为医疗诊断依据"。
    *   **术语脱敏**：系统自动将医学诊断词汇转化为养生调理词汇。

### 3.4 扩展模块：购物导流（V1.1）
*   **需求描述**：点击推荐产品跳转至第三方电商平台。
*   **功能点**：
    *   **外链跳转**：点击"去购买"跳转至京东/天猫相应搜索页或商品详情页。

## 4. 用户流程 (User Flow)
1.  **进入首页**：简洁的搜索框界面，提示语"您最近哪里不舒服？"。
2.  **输入症状**：用户输入或点击预设标签（如：护肝、明目、助眠）。
3.  **AI分析中**：显示加载动画，增加仪式感。
4.  **结果展示**：
    *   分析结论（可能的原因）。
    *   养生建议（饮食、作息）。
    *   **推荐组合**（产品图片 + 名称 + 核心功效）。
5.  **后续行动**：重新咨询 或 查看产品详情（跳转）。

---

## 5. 非功能需求
*   **易用性**：字体需支持放大模式，适配老年用户。
*   **响应速度**：AI生成回复时间控制在3秒内。
*   **安全性**：用户输入的健康数据需加密存储，保护隐私。
*   **合规性**：所有推荐内容需经过敏感词过滤系统。

---

## 6. 数据需求
*   **症状-产品映射库**：需建立一套结构化的数据库，包含：
    *   症状关键词 -> 中医证型 -> 推荐食材/产品。
*   **敏感词库**：包含所有禁止在养生建议中出现的医疗术语。

---

## 7. 迭代规划
*   **第一阶段 (MVP)**：实现基础对话与文本推荐，建立核心数据库。
*   **第二阶段 (商业化)**：接入电商API，实现佣金结算。
*   **第三阶段 (智能化)**：引入视觉识别（如舌象识别），提升推荐精准度。
